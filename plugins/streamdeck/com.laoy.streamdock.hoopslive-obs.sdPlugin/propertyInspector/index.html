Setup en 1 collage. Pas besoin de chercher le token à la main si ton URL OBS contient déjà ?k=….

  1. Sur le VPS, note HOOPSLIVE_OBS_TOKEN (fichier .env du store).
  2. OBS → Source Navigateur → URL
    https://hoopslive.ch/hl-obs/<secret>/scenes/start.html?k=<token>
  3. Colle cette même URL ci-dessus → Appliquer → Tester.
