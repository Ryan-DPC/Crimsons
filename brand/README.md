# CRIMSONS brand system

Logo system proposals structured like HOOPS LIVE (icon / monogram / wordmark light+dark / social cover).

## Palette

| Token | Hex | Usage |
| --- | --- | --- |
| Crimson | `#B31B32` | Primary accent (matches store `--accent`) |
| Crimson bright | `#E8344A` | Highlights on dark |
| Crimson deep | `#8B1526` | Shadows / light-surface accents |
| Ink dark | `#141418` | Wordmark on light |
| Ink light | `#F0F0F4` | Wordmark on dark |
| Surface dark | `#0E0E11` | App / cover backgrounds |

## Proposals

| ID | Folder | Direction |
| --- | --- | --- |
| **A** (favorite) | `proposals/a-geometric-c/` | Geometric **C** + hex-node — vector evolution of the desktop login mark |
| **B** | `proposals/b-pulse-signal/` | Pulse / signal arcs — HOOPS-Pulse echo with crimson identity |
| **C** | `proposals/c-sharp-cs/` | Sharp shield + CS slash — gaming / StreamDock energy |
| **D** | `proposals/d-wordmark/` | Typographic wordmark + crimson slash — minimal companion mark |

Each proposal folder contains:

- `favicon.svg` — 16–32px solid mark
- `logo-icon.svg` — hi-res app / header icon
- `logo-monogram.svg` — letter / signal mark alone
- `wordmark-light.svg` — for light backgrounds
- `wordmark-dark.svg` — for dark UI
- `cover-social.svg` — 1200×630 social cover
