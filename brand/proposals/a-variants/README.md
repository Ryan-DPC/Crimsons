# Geometric C — variants (theme A)

Refinements of favorite **A0 Geometric C**. Same DNA: geometric letter C + technical crimson node.

| ID | Name | Idea |
| --- | --- | --- |
| **A0** | Geometric C | Baseline (hex outline + diamond + plug) — `../a-geometric-c/` |
| **A1** | Soft Gap | Softer gap terminals (rounded plug), softer hex nodes |
| **A2** | Sharp Diamond | Flat C, chiseled opening, losange node only |
| **A3** | Outline Pin | Stroke C + solid square pin (connector) |
| **A4** | Badge App | Rounded-square crimson badge, inverted white C |
| **A5** | Minimal | Ultra-simple C + single node — favicon-first |
| **A6** | Hex Fill | Solid filled hex node in the C gap |

Each folder: `favicon.svg`, `logo-icon.svg`, `logo-monogram.svg`.
Shared wordmarks: `wordmark-light.svg`, `wordmark-dark.svg`.
